# Мекеги — демонстрация сайта, Telegram и CRM

Опубликованная версия: https://jonessssenator-art.github.io/mekegi-demo/

Макеты обновлены по предоставленной «Мекеги-презентации.pdf»: первый экран сайта, история бренда, корпоративные заявки, повтор заказа, кабинет владельца, клиенты, аналитика и себестоимость товаров. Изображение первого экрана извлечено из презентации; фотографии каталога и логотип — из Instagram пекарни (ссылки в `demo-src/sources.json`).

## Изменение и проверка

Редактируйте `demo-src/index.html`, `style.css`, `app.js`, `business.js`. `realtime.js` — адаптер уже существующего сервера.

```sh
node --test demo-src/business.test.cjs
python3 demo-src/build_standalone.py
cp demo-src/mekegi-presentation.html index.html
python3 -m http.server 8766
```

Сборка встраивает все фотографии и скрипты в корневой `index.html`. Шрифты загружаются с Google Fonts с системным запасным вариантом.

## Что работает в демонстрации

- Корзина, оформление и повтор заказа по текущим ценам. Недоступные товары при повторе пропускаются.
- Статусы заказов, кухня, доступность товаров на обеих витринах.
- Корпоративные заявки с датой, гостями, бюджетом и статусом.
- Выручка, валовая прибыль, средний чек, постоянные гости, динамика и каналы за 7 / 30 / 90 дней.
- Экономика товаров с сортировкой и CSV; история клиентов по нормализованному телефону.
- Адаптация к телефону; таблицы превращаются в карточки.

Все цены и финансовые данные демонстрационные. В аналитике учитываются только завершённые заказы по дате завершения. Валовая прибыль — оценка по текущей прямой себестоимости из каталога, без аренды, налогов, доставки и общих расходов. Изменённая сумма заказа распределяется между товарами пропорционально стоимости позиций. Бюджеты корпоративных заявок не являются выручкой.

При первом открытии добавляется демонстрационная история продаж; существующие пробные заказы сохраняются. История стареет по календарю, поэтому со временем демонстрационные показатели периода уменьшаются.

## Ограничения запуска

GitHub Pages размещает статическую демонстрацию. `MEKEGI_API_URL` пуст: заказы, корпоративные заявки и себестоимость сохраняются только в браузере. Общий сервер между устройствами, Telegram-бот, оплата и уведомления не подключены.

Папка `realtime-server` содержит подготовленную серверную часть обычных заказов. При подключении этого сервера корпоративные заявки и себестоимость пока остаются локальными — их серверное хранение требует отдельной интеграции. Для реального запуска нужно согласовать ассортимент и цены, развернуть сервер, настроить доступ и проверить сценарии.
